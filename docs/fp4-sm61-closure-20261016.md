# FP4 formats on sm_61 — closure audit

Base: `fp4_candle` at `366b199c0789c429614adb256edaaa1c675810e8`.

## Format and execution contracts

MXFP4 GGUF remains E2M1 with E8M0 block-32 scales. ModelOpt NVFP4 remains a
separate packed E2M1 payload with E4M3FN block-16 scales and a global FP32
multiplier. Neither format is relabeled or silently converted into the other.
NVFP4 W4A16, W4A8 reference and W4A8 DP4A remain explicitly selected modes.
Pascal does not acquire native FP4 Tensor Core arithmetic from this feature.

## Corrections found during audit

- Fixed the NVFP4 reader's ambiguous comparison of `Vec<usize>` with `[]`,
  which prevented compilation when the reader was actually enabled.
- Made the real ModelOpt reader available without CUDA for offline validation.
- Share packed-payload validation between the reader and native constructor;
  reject scales/global factors that overflow the kernels' FP32 dequantization.
- Check activation/output counts and Q8 padding before allocation and signed
  CUDA indexing. A weight matrix fitting i32 alone is insufficient.
- Reject cross-context raw buffers and mismatched Candle CUDA devices.
- Preserve the existing examples feature alias, and apply the ZIP 9 migration
  required for fresh dependency resolution and checkpoint filename APIs.

The new self-contained GPU test exercises W4A16 against a scalar host oracle,
and W4A8 reference against DP4A, with N=5, K=64 and M=1/3/8/9/17. It needs no
checkpoint fixture and covers partial tiles plus Q8 padding. It does not assert
that W4A8 is mathematically identical to W4A16.

## Validation

- CPU: the complete `candle-core --no-default-features` suite passed
  (264 tests, including documentation; 4 ignored).
- CUDA: NVCC 12.9.86 compiled the real kernels for `sm_61`; Rust 1.99.1
  `cargo check -p candle-core --features cuda,cuda-legacy-fp4 --tests` passed.
- Physical GPU execution of this revision: **PENDING**.
- Existing benchmark-only gates remain opt-in; no automatic performance promotion.

Run the self-contained qualification on the physical Pascal card:

```bash
export CUDA_COMPUTE_CAP=61
export NVCC_CCBIN=gcc-14
cargo test --release -p candle-core --features cuda,cuda-legacy-fp4 \
  --test mxfp4_tests --test fp4_e7c_contract --test nvfp4_loader_tests -- --nocapture
```

The external-checkpoint E7B full-forward and E7C fixture-dependent tests remain
separate and ignored by default. This revision does not add KV-cache or generic
autoregressive ModelOpt model integration. Requalify Legacy/Extended before promotion.
